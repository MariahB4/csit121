Reflection 1: HTML Basics

Starting out with HTML was actually a lot of fun. It’s cool to see how simple tags like <header> and <article> act like the 'skeleton' that holds everything together. I did run into a few headaches with missing closing tags, which made my layout look a bit wonky, but using the W3C Validator helped me find exactly where I messed up. It's satisfying to see the code go from a messy draft to a clean, structured page.

Reflection 2: CSS Basics

This module was a big eye opener because now I'm finally ableto see how CSS brings a plain page to life. It was really cool how I could change one line in my stylesheet and suddenly my whole blog had this dark, neon look. I spent some time playing around with IDs and classes to get the glowing headings just right, though I had to be careful that the colors weren't too bright to actually read.
